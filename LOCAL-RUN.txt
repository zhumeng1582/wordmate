本地运行入口（0.1）

先在自己的终端执行：
cd /Users/mac/Desktop/word
corepack pnpm install

安装成功后执行：
node scripts/local-dev.cjs

这条命令会编译后端、检查小程序类型、构建微信小程序，再启动后端。
任一步出错即停止，不会把失败当成启动成功。
本地数据库自动初始化并保存在 .local/dev-db，重启保留学习记录。
不需要安装 Docker，不需要购买云服务器，不需要填写 .env 或服务密钥。
调度使用真正的 ts-fsrs；没有替代算法或静默降级。

微信开发者工具：
1. 安装微信开发者工具（微信客户端不能代替它）。
2. 导入 /Users/mac/Desktop/word/apps/miniapp，AppID 已配置。
3. 只在本地开发时，在工具项目设置中勾选不校验合法域名。
4. 运行：家庭与孩子 → 开发登录爸爸 → 创建家庭和孩子 → 单词本 → 建本 → 输入 apple、book → 确认 → 首页复习。

当前开发模式词库只有 10 个词，账号为显式的开发身份。
它使用真实本地数据库保存记录；这些记录不要导入正式环境。
本轮没有接通 AI 例句和语音播放，不会假装这些服务已生成结果。

HTTP 验收（后端 build 成功后）：
corepack pnpm test:smoke
使用独立的 .local/smoke-* 数据库和 3137 端口，验证 HTTP 全流程及真实 FSRS。
