本地运行（按当前工作区代码整理，2026-11-10）

1. 安装仓库要求的 Node.js 与 pnpm（packageManager 为 pnpm 10.11.0），在项目根目录运行：
   corepack pnpm install --frozen-lockfile
2. 执行：
   node scripts/local-dev.cjs
   脚本先检查 3000 端口，再构建 API、检查小程序类型、构建并检查产物，最后启动本地后端。开发身份仅限本机使用；本地 PGlite 持久数据位于 .local/dev-db，已有数据不会因为正常重启自动清空。
3. 在微信开发者工具导入 apps/miniapp；仅本地开发时关闭合法域名校验。开发构建连接 http://127.0.0.1:3000/api，不能直接用作生产包或跨设备连接地址。

本地不配置 AI、语音或存储凭证，也可启动并检查不依赖这些服务的功能；真实 AI 整理、图片识别、朗读或语音聊天需要相应服务端配置和网络权限。脚本在构建完成后才从被忽略的 .env 注入供应商配置到后端；不要提交密钥，也不要把生产凭证放入小程序。示例配置见 .env.example 和 config/。首次开发启动缺少 AI_CREDENTIAL_KEY 时，脚本会在 .local 生成开发密钥。

单词、诗词、汉字均有独立入口，具体录入、打卡、归档和限制分别见 apps/AI-VOCABULARY.txt、apps/POEMS.txt、apps/HANZI.md。PDF 处理需要系统安装 Poppler（pdfinfo、pdftotext、pdfimages、pdftoppm）；图片页还需要可用的视觉模型。语音播放代码已接入，是否可以播放取决于实际音色、额度、服务端和微信环境。

常用检查（项目根目录）
  corepack pnpm verify
  corepack pnpm build:api
  corepack pnpm --filter @wordmate/miniapp typecheck
  corepack pnpm build:miniapp
  corepack pnpm test:routes
verify 是离线工程检查，不等于真实 AI、云存储、微信登录、支付或真机验收。test:ai:live、test:ocr:live、test:tts:live、test:ai:flow 等真实服务测试可能产生费用，应先检查配置和测试范围。

发布包的环境变量、迁移、备份和发布前检查见 ARCHITECTURE-OPERATIONS.md 与 infra/SERVER-DEPLOYMENT.txt。当前工作区可能含未提交改动；本地构建和开发运行均不代表生产已更新。
