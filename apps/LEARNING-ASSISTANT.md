# AI 学童学习任务

2026-11-11：首版已合并至 AI 学童，后端已发布至 2026-11-11-agent-f34ef6；小程序正式包已构建，仍需上传并在微信真机联调。本地功能验证使用注入的 AI/TTS 响应，没有调用真实付费服务；模型语言质量、真实音质和微信真机布局仍需联调。

当前实现只使用原来的 pages/word-tutor/index 聊天界面，已删除 AgentChat 界面及其样式。学习时从原 AI 学童入口进入，在同一段对话里询问最近学习、练习错词或生成文章；没有单独的欢迎页、日期工具栏和另一套输入区。原单词讲解、输入、语音和消息展示继续保留。设置入口恢复为 AI 学童聊天记录，首页不增加独立入口。旧通用聊天在打开时保留消息、文章和练习进度，并接入原聊天界面。诗词与汉字继续使用原讲解界面。

支持：
- 今天、最近 7 天、最近 30 天的实际学习词查询；自由提问可解析自定义日期，服务端限制单次跨度不超过 90 天、不查询未来。
- 查询范围内的错词，或用这些错词生成文章。学习依据来自 daily_word_activity / mistake_events，不能把新增词当作学过的词；排除已归档词。最多展示 200 个词，并明确标识超过上限；文章选用最多 12 个目标词。
- 生成带逐段译文的英文文章，点击高亮词查看当前词义，展开/收起译文，朗读英文全文。覆盖统计采用目标词原形的完整边界匹配，未覆盖的目标词单独列出；尚不自动统计所有屈折词形，机械校验不能证明义项使用和英语质量正确。
- 沿用当前文章选词改写难度、主题和长度；根据文章生成 3 道单项选择题，逐题反馈，服务端判断答案并持久保存进度。题目答案不提前传给客户端。
- 会话自动恢复、历史切换、删除；最多 200 条消息，读取最近 100 条。长会话达到限制时新建对话。
- 读取孩子已有年级以调整内容；首次使用告知相关记录、年级和对话会发送给所选 AI 服务。

服务端使用白名单任务规划与受限查询，模型不能执行 SQL 或选择其他孩子。自然语言任务最多「规划 + 生成」两次模型调用；快捷统计不调用模型。任务所需调用全部成功、业务保存成功后再一起结算，否则释放费用。请求 UUID 防重复，会话内同一时间仅运行一个任务，超过 10 分钟的请求失效并释放预留。

费用沿用系统家庭额度 / 个人 AI 配置，历史分类显示「AI 学童（学习任务）」；文章新朗读按现有语音字符价格结算，同一消息、音色及模型配置重复播放复用缓存。删除会话级联删除文章、题目、进度、消息和音频。删除孩子最终也会级联清理；阅读练习不写入 daily_word_activity、review_logs 或单词掌握状态。

部署：
1. 构建 API：corepack pnpm build:api。
2. 已使用迁移账本的环境运行既有 migrate:managed apply，应用 052_learning_assistant.sql。初次空库迁移和本地嵌入式数据库初始化已包含此迁移。不在现有正式库重新运行初次迁移。
3. 部署构建后的 API 和 packages/ai/dist，重启后端；沿用已有文字和语音配置，无新供应商密钥。
4. MINIAPP_API_BASE=https://实际域名/api corepack pnpm build:release，上传新版小程序。
5. 联调：实际学习几个单词 → 学习页打开原 AI 学童 → 在原对话询问最近学习、练习最近错词或用今天的词写故事 → 译文/朗读 → 自然语言要求简单一点或考考我 → 离开返回续题；同时检查额度和跨家庭访问拒绝。
