# 管理后台

第一版为单管理员内部工具，只监听服务器的 `127.0.0.1:8787`，不应配置公网反向代理。运行时使用现有数据库配置，不向浏览器暴露数据库凭证。启动时生成一次性随机访问凭证；每次重启后旧链接失效。保持 SSH 会话运行，退出时按 Ctrl-C 关闭后台。

在本机终端建立隧道（将服务器地址换为实际部署地址）：

```sh
ssh -L 8787:127.0.0.1:8787 root@服务器地址
```

在 SSH 会话中进入服务器当前发布目录，使用该发布的生产环境文件启动：

```sh
node --env-file=/生产环境文件的实际路径 apps/admin/server.cjs
```

在本机浏览器打开终端给出的完整地址（包含 `#` 后的凭证）。凭证只放在浏览器内存，刷新页面需要重新使用完整地址。不要分享地址，不要将启动输出写入公共日志；用完关闭程序和隧道。若本机端口冲突，可将服务器 `ADMIN_PORT` 和 SSH 隧道的两端端口设为同一个空闲端口。

发音反馈可选择已生成的受影响音频、指定同口音的候选音色并生成试听，确认后才替换该音频。生成使用平台语音服务并可能产生供应商费用，不扣用户家庭余额；管理用量统计记录次数，具体费用以供应商账单为准。原反馈没有指定音频时，替换后仍为处理中，管理员核实后可填写备注并标记解决。音频修复只影响选中的孩子、词条或例句及原音频设置；替代音色可能与用户原选音色不同。用户需要使用支持刷新音频缓存的小程序新版本才能在页面保持打开时立即获得新音频。生成失败或提交超时也可能产生供应商费用，重试前请先刷新检查。

其他反馈的状态和备注只记录处理过程，暂不修改词条、例句或 AI 讲解。反馈内容可能包含用户提供的文本，仅授权人员可查看；备注不要记录额外个人信息。用户和词库只读，AI 用量为应用内账本统计，不代表供应商实际账单。当前暂无直接修词、AI 自动建议、多个独立管理员账号或通知功能。

在“单词库”中先选择单词本，再查看其单词、词性、中文翻译、最新有效例句及中文翻译；搜索和分页只在当前单词本内进行。试听只读取该内容当前版本已经生成的音频，可选择不同口音和音色，不会调用语音合成或扣费。没有音频时显示“暂无音频”。共享词库的内容是发布时的快照，不关联个人音频，因此显示暂无音频。

本地验证：`node --test apps/admin/admin.test.cjs`（需要允许监听本机回环端口）。
