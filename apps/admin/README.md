# 管理后台

第一版为单管理员内部工具，只监听服务器的 `127.0.0.1:8787`，不应配置公网反向代理。运行时使用现有数据库配置，不向浏览器暴露数据库凭证。启动时生成一次性随机访问凭证；每次重启后旧链接失效。保持 SSH 会话运行，退出时按 Ctrl-C 关闭后台。

在本机终端建立隧道（将服务器地址换为实际部署地址）：

```sh
ssh -L 8787:127.0.0.1:8787 root@服务器地址
```

在 SSH 会话中进入服务器当前发布目录，使用该发布的生产环境文件启动：

```sh
node --env-file=/生产环境文件的实际路径 apps/admin/server.cjs
```

在本机浏览器打开终端给出的完整地址（包含 `#` 后的凭证）。凭证只放在浏览器内存，刷新页面需要重新使用完整地址。不要分享地址，不要将启动输出写入公共日志；用完关闭程序和隧道。若本机端口冲突，可将服务器 `ADMIN_PORT` 和 SSH 隧道的两端端口设为同一个空闲端口。

发音反馈可选择已生成的受影响音频、指定同口音的候选音色并生成试听，确认后才替换该音频。生成使用平台语音服务并可能产生供应商费用，不扣用户家庭余额；管理用量统计记录次数，具体费用以供应商账单为准。原反馈没有指定音频时，替换后仍为处理中，管理员核实后可填写备注并标记解决。音频修复只影响选中的孩子、词条或例句及原音频设置；替代音色可能与用户原选音色不同。用户需要使用支持刷新音频缓存的小程序新版本才能在页面保持打开时立即获得新音频。生成失败或提交超时也可能产生供应商费用，重试前请先刷新检查。

其他反馈的状态和备注只记录处理过程，暂不修改词条、例句或 AI 讲解。反馈内容可能包含用户提供的文本，仅授权人员可查看；备注不要记录额外个人信息。用户和词库只读，AI 用量为应用内账本统计，不代表供应商实际账单。当前暂无直接修词、AI 自动建议、多个独立管理员账号或通知功能。

在“内容管理 → 按单词本查看”中先选择单词本，再查看其单词、词性、中文翻译、最新有效例句及中文翻译；搜索和分页只在当前单词本内进行。试听只读取该内容当前版本已经生成的音频，可选择不同口音和音色，不会调用语音合成或扣费。没有音频时显示“暂无已生成音频”。共享词库的内容是发布时的快照，不关联个人音频，因此显示暂无音频。

本地验证：`node --test apps/admin/admin.test.cjs`（需要允许监听本机回环端口）。


## 数据库运营成本

在管理后台选择“数据库成本”，按中国时区月份查看。该功能手动记录云账单，不会自动读取阿里云账户，也不会购买、退订资源、调整数据库规格或扣除家庭 AI 钱包。

- **RDS 账单**：录入已扣除节省计划抵扣、且不含计划自身费用的 RDS 应付金额。不能填抵扣前原价、账户充值额或数据库节省计划购买金额。一个月份保留一条合计记录，可修改纠正。
- **截止日期与整月状态**：当前月可填累计账单及其截止日期；已核对整月最终账单时选择月末并勾选整月确认。RDS 费用和计划摊销始终使用同一截止日期。缺少账单时合计显示“待录入”；真实零费用须明确录入 0。
- **已购买计划**：按实际合同录入名称、唯一订单号/合同编号、优惠后的整个承诺期总成本、开始日期和最后有效日。全预付为实际合同费用；半预付和 0 预付不能只填首笔付款。待购买报价不应录入，页面不预填截图中的价格。
- **摊销**：以有效期自然日分配合同成本，最后有效日包含在内；月中生效、跨年和闰年均按实际天数计算。累计分配使用整数微元，整个有效期累计恰好等于合同总成本。小时级生效时间会有日粒度估算差异，官方账单仍是对账依据。
- **合计**：RDS 抵扣后应付 + 当前截止日期内的节省计划摊销；不包含 ECS、OSS、AI 等其他运营费用。不要将原价账单再与计划费用相加。
- **纠正记录**：同一订单不能重复录入；修改计划会重算相关月份。错误或重复记录可“排除此条记录”，以后可以恢复统计，这不是退订云服务。多人/多标签页同时修改时，旧版本保存会被拒绝，刷新核对后再修改。

记录默认保存为音频 spool 父目录中的 `admin-database-costs.json`，与 release 目录分离；生产模板对应 `/var/lib/wordmate/admin-database-costs.json`。可通过绝对路径 `ADMIN_DATABASE_COSTS_FILE` 指定其他受保护的持久目录。文件以 0600 权限、版本检查、排他锁和临时文件原子替换保存，不新增业务数据库表。

部署时需同时包含 `apps/admin/database-costs.cjs`、`database-costs.js`、现有 HTML/JS/CSS 与更新的 `scripts/server-backup.cjs`。日备份会在成本文件存在时复制该文件，并在 manifest 的 `database_costs` 项记录文件名、字节数和 SHA-256；未录入时不创建空账单。恢复时核对摘要，将备份副本放回原持久路径并保持 0600 权限；不要用空文件覆盖损坏记录。异常终止若遗留 `.lock` 文件，先确认没有管理后台进程正在保存，再由管理员清理遗留锁后重试。

验证：`node --test apps/admin/*.test.cjs scripts/test/server-backup-costs.test.cjs`，其中 HTTP 测试需要允许监听本机回环端口。完整 `corepack pnpm verify` 已纳入管理后台测试。


## 内容与任务运营查询

2026-11-19 本地新增三个入口，复用现有内容、任务、纠错和账本记录，不新增业务表：

- **内容管理**：查询英语单词、英语句子、古诗词和汉字，按类型、状态、个人内容/含共享副本、孩子 ID 和关键词筛选。查看所选内容字段和单词关联例句，不展示孩子私有笔记、标签或账号凭证。共享副本指已加入孩子内容本的本地副本；已发布共享单词快照仍可通过“按单词本查看”查询。
- **导入任务**：统一显示四类任务的当前状态、已保存条数、待核对条数、分批/阅读进度、执行租约和错误码。单词批量任务结合子批次状态计算，避免父任务滞后导致误判。任务明细已清理时保留历史记录并提示；本入口仅列任务来源记录，不包含手动新增记录，不提供重新生成、重试或取消操作。没有展开原始上传材料、文件名、base64 或供应商原始响应。
- **AI 纠错**：查询内容和发音纠错的完成、失败、排队及撤销记录，查看选定字段的历史前后值、有限校验信息和发音音素。历史快照不代表当前词条。供应商成本仅汇总 `ai_calls` 已记录值，并显示有成本记录的调用次数；用户收费单独统计。缺少成本不当作零，账本不等同供应商最终账单。本入口不直接修改内容或重新发起收费任务。

内容详情与单词本试听只读取当前版本、当前语音配置下已生成资源。对相同口音、音色及语速，优先使用当前内容上下文匹配且未撤销的 AI 纠错音频；撤销或正文变化后失效。AI 纠错记录详情只在该记录音频仍有效时提供当前内容试听。古诗词和汉字读取匹配内容哈希及运行配置的数据库缓存。所有试听都不调用语音合成，不额外扣费；切换页面、收起详情或重新读取时停止旧播放器，迟到响应不会开始播放。

上述接口沿用回环监听、管理凭证、来源校验和禁止缓存策略；新增查询接口均为 GET。已有反馈管理的“生成候选音频”是独立的显式收费操作，行为不变。

发布时还需包含 `operations.cjs`、`operations.js`、`content-audio.cjs`、`library.cjs` 和对应 HTML/JS/CSS、server 文件。先执行 `corepack pnpm build:api`，管理端复用编译后导出的内容哈希和语音配置规则，不能只上传新 admin 文件搭配旧 API dist。没有新增迁移。此段记录开发范围，不代表已部署。
