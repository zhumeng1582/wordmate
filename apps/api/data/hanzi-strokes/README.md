# Stroke graphics source

`graphics.txt.gz` is the unmodified `graphics.txt` from [Make Me a Hanzi](https://github.com/skishore/makemeahanzi), compressed with gzip. The upstream graphics are derived from Arphic PL KaitiM GB and Arphic PL UKai, and distributed under the Arphic Public License, included here as `ARPHICPL.TXT`. Copyright (C) 1999 Arphic Technology Co., Ltd. Upstream copyright and attribution: https://github.com/skishore/makemeahanzi/blob/master/COPYING

The decompressed file contains 9,574 entries; SHA-256: `a28c478b5178e98f67f510b2d52fde08a69dc664654ef43498253b9b764d46ee`.

These graphics have not been verified against every character in the current mainland teaching standard; they are presented as a reference with a note to follow the textbook. The app does not show them when the data contains more than 30 strokes or the user's declared count disagrees.
