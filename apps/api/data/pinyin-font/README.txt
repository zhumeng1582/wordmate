WordmatePinyin is a Latin/pinyin subset of Noto Sans Regular (SIL OFL 1.1).
The modified font is renamed WordmatePinyin. Attribution and license: OFL.txt.

Subset built with fontTools 4.60.2, Unicode ranges U+0020-024F,
U+0300-036F and U+1E00-1EFF. metrics.json records the resulting Unicode
to glyph ID and advance width mappings (1000 units/em), plus font bounds.
Keep the TTF and metrics together when rebuilding. Both are embedded by
hanzi-copybook.ts; no system font or runtime font dependency is required
for Latin text, tone-marked vowels, or umlauts in generated copybooks.
