# 教材与词表来源调查

调查日期：2026-11-02。以下链接是内容调研和核对线索，不代表已获产品分发授权，也不代表已逐项核实词表正确性。

## 官方平台

- [外研社新起航英语教学资源](https://www.unischool.cn/xzfw/xqhyy/ynjsc/)：四册各五个单元均有教学设计。已下载 20 份教学设计，从“核心单词”或“核心词汇”段落提取 147 个单元词条（143 个不区分大小写的不同词项），保留首次出现顺序，并添加自行编写的中文释义。教案核心词汇不等于经核实的教材完整词表；教材内容的发布使用范围仍需核实。
- [国家中小学智慧教育平台电子教材](https://basic.smartedu.cn/elecEdu)：教育部表示平台资源免费使用；本次工具访问电子教材入口超时，未能核对具体册次或下载条件。免费浏览与在其他产品中发布教材词表是不同用途，需针对具体内容确认使用条件。
- [人教社小学英语配套资源](https://www.pep.com.cn/zslth/yyptzy/xyjt/3s/)：列有 PEP、精通各册和单元 Vocabulary 资源。页面版本及对应教材需逐册核实，不可直接视为 2024 版词表。
- [掌上外研 App](https://apps.apple.com/cn/app/%E6%8E%8C%E4%B8%8A%E5%A4%96%E7%A0%94-%E5%A4%96%E7%A0%94%E6%95%99%E6%9D%90%E5%AD%A6%E4%B9%A0%E8%BD%AF%E4%BB%B6/id6758136183)：介绍称配套新起航英语，注册后需激活码获取电子教材等资源。本次未登录，也未获取电子书或词表。

## 社区候选数据

- [qwerty-learner 社区提交](https://github.com/RealKai42/qwerty-learner/issues/1044)：提交者称提供 PEP 三年级上下册（2024）和四年级上册（2025）JSON。三个附件已下载到本机临时目录，分别含 106、113、109 条，字段包括英文、释义和音标；未发现单元字段，尚未对照教材核验完整性、版本和授权。它们不进入正式内容库。
- [pep-english-words](https://github.com/cyforkk/pep-english-words)：提供结构化教材词库，并说明其源词表来自另一个仓库、单元边界由脚本切分；需确认具体版本、数据权利及单元准确性。项目代码许可不自动证明第三方教材内容可再分发。
- [沪教版词表 gist](https://gist.github.com/amio/033afeac8b3660c0a488262355a39165)：有按单元整理的词汇，版本及权利信息未核实，页面中也有疑似拼写错误，不能直接上线。

## 后续核验

逐册记录 ISBN、主编、修订年份、来源及许可，并与对应正式教材核对每个单元的词条和顺序。仅找到可下载文件不等于完成核对；缺少单元信息的词表不能标为教材同步。新起航、其余教材尚未找到已核实且可供本产品使用的完整词表。
