# 教材词本内容准备

`catalog.json` 现只保留新起航英语预备级，覆盖一、二年级。小程序按册提供教材词本，也可在共享词本中搜索。

每册入库前需要核对出版社、系列、主编、起点、学制、修订年份、年级、上下册及 ISBN，并保存词表来源、使用许可和审核记录。外研社不同主编系列及 Join In 的对应关系需逐册核实，避免同一教材重复建档。教材名、书名、封面、词表、原文、例句和音频的使用范围应分别确认。词表按单元和原顺序整理，记录单词、词性、适合教材语境的释义；补充的发音和例句也需校对。

正式功能需使用独立的平台教材目录，按用户选择加入孩子词本，保留教材单元和顺序；与孩子已有单词的学习进度去重，不因移除一个词本而删除其他词本仍使用的进度。加入应幂等，教材更新不得静默覆盖已有学习数据。加入整册后的新词投放须与现有学习队列的每日限制一起验证，避免一次性产生过量学习任务。

一年级上下册、二年级上册，以及二年级下册的 Unit 1、Unit 3 使用用户提供的词表。二年级下册其余三个单元暂保留外研社教学设计中的核心词汇，不能视为完整课本词表。中文释义为学习场景编写；来源及进一步核对情况见 SOURCES.md。
