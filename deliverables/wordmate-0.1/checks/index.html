验证与验收报告

交付总览需求文档页面设计技术方案数据库接口契约验证报告

以下为本地实际执行结果；不是服务端端到端或真机验收报告。

数据库结构与约束

  • 29 张表初始迁移执行成功
  • 家庭与管理员成员延迟外键同事务创建成功
  • 跨孩子单词关联被复合外键拒绝
  • 同孩子同义项重复写入被拒绝
  • 同孩子第二个 active 陪学会话被拒绝
  • 关闭旧租约后可以接管
  • 同一天同一卡片不重复计词数
  • 同义项不同题型也不能重复计每日词数
  • 同孩子复习 event_id 持久去重
  • 删除家长不会级联清空家庭和学习数据
  • 简单与易错标注互斥
  • 标注不能跨孩子引用
  • 抽样测验不能省略样本数量
  • 同孩子不能有两份活动月测
  • 测验月份必须存月初日期
  • 月测题目不能跨孩子引用
  • 满分不得写成合格等级
  • 重复交卷不能重复归集同题错误
  • 错题来源必须与来源引用匹配
  • 错题事件不能跨孩子引用
  • 四档分数线59/60/79/80/89/90/100数据库约束验证通过（候选去重仍属应用校验）
  • 额外练习允许卡版本不变并保留审计事件
  • 重复删除目标不创建第二个生命周期任务
  • 完成状态必须同时具有完成阶段和时间
  • 孩子及唯一成员家庭物理删除后，两项删除任务结果仍保留；延迟管理员外键允许同事务清理

接口Schema与样例

  • 例句修改管理员契约、独立删除任务查询及家庭解散接口存在（不替代运行时鉴权测试）
  • 月测模式、月份格式、样本数必填、复习来源互斥及标注互斥Schema校验通过
  • 未交卷题目DTO不含答案或词义快照
  • 89 个操作路径、参数和 operationId 校验通过
  • 919 个本地引用解析通过
  • 60 个 JSON Schema 编译通过
  • 基础请求合法样例、非法评分和双音频目标拒绝通过

  • 原型交卷后禁止返回可修改作答页

验证边界

  • 使用内嵌 PostgreSQL 16.4 验证 DDL 与约束；未验证正式服务端、鉴权中间件或多连接并发。
  • OpenAPI 进行结构、引用、Schema 编译与样例校验；未运行完整 OpenAPI 规范元 Schema 校验器。

授权Guard、业务状态机、队列崩溃恢复、供应商实际质量和多连接竞态需要实现后测试。本包约束不替代应用层状态机。文档对这些规则已有明确设计与验收项。
