0.1 音频缓存优先流程与资源交接
更新：2026-10-21

实现边界
已有：packages/ai 的 CosyVoice 北京 HTTP 合成适配器、音色白名单、音频格式校验、audioCacheKey；初始数据库 audio_assets 表；OpenAPI 音频与任务接口契约。
待实现：音频业务 Worker、OSS 适配与鉴权下载、小程序播放控制、公共标准词条缓存及增量迁移。本文件是实施规格，不代表上述流程已经运行。真实合成、音质与手机播放须在账号配置后验收。

一、用户流程
点击词条或例句的播放按钮 → 校验家庭成员与内容版本 → 计算音频键 → 查询可用音频。
命中：读取私有 OSS 文件 → 后端鉴权下载 → 小程序临时文件 → 播放，不调用 TTS。
未命中：持久任务入队 → 页面显示“首次生成中” → Worker 合成 → 校验文件 → 上传 OSS → 校验上传成功 → 更新可用状态 → 下载播放。
同一音频正在生成：复用任务/缓存对象，显示生成中，不再创建合成请求。不同家庭只能看到自己的授权任务句柄，不公开全局任务、使用者或命中来源。
客户端每2秒查询一次任务，页面隐藏停止查询；30秒仍未完成提示“可稍后再试”，不当作生成失败，不取消后台任务。继续点播仍查询原任务。
前端同一时刻只播放一个音频；切词、切口音、切孩子、退出页面时停止并销毁播放器。慢请求完成后检查当前播放意图，不能突然播放上一条。
当前默认语速1.0；英音/美音独立缓存，音色不符明确提示，不自动替换口音。暂不预生成整个词本或两种口音，按需生成。

二、缓存粒度与范围
音频键包含：环境、公开标准词条或私有孩子范围、准确朗读文本、发音区别标识、供应商、地域、模型、音色、口音、语速、MP3/24kHz、合成策略版本。
文本只做Unicode NFC与首尾空白规范化；不无条件转小写，不移除标点。US/us、read的不同时态、record的不同词性不能因拼写相同误合并。
共享标准词：仅受信词典/经审核公共词条，其来源、词形、读音身份及版本可验证时跨家庭复用。共享的是文件字节，下载仍须具有本人词条或受限词典查询资格。
AI录入或用户自定义词默认私有，不能只凭“看起来是英文”纳入全局缓存；姓名、短语与所有个性化例句默认按孩子隔离。当前尚无已验证生产词典来源时，共享标准词功能保持关闭，私有缓存照常节省重复播放成本。
私有词/句的内容版本单独校验；改词义、音标或句子后旧资源不能直接冒充最新版本。若仅词义变化且确定不影响读音，可在后续审核规则中显式复用，不自动猜测。
更换模型或合成策略产生新缓存键，旧文件无需立即批量重建。

三、数据与迁移方案（未执行）
保留 audio_assets 的孩子/词条/句子授权绑定，不把 child_id 改成可空。
新增 audio_cache_objects：唯一 cache_key；scope(public_dictionary/child)、scope_id；合成参数快照；状态、attempts、next_run_at、lease_until、fencing_token；storage_key、sha256、size_bytes、mime_type；错误码、创建/访问时间。
audio_assets 增加 cache_object_id 外键和内容版本绑定。标准公共词的多个孩子绑定可引用同一对象；私有内容只能引用同孩子对象。此条件在事务服务校验，不能由客户端提供 cache_object_id。
新增 audio_usage_events：实际外呼前按尝试追加事件，记录发起账号、孩子、缓存对象、合成字符数、尝试ID、时间和供应商请求ID（如有）。事件不存原文或密钥；重试不会重置额度，按事件时间统计而非覆盖job时间。
generation_jobs 保持家庭范围的任务句柄；并发等待者依缓存对象完成，不消耗新的合成次数。不向其他家庭暴露对象所有者或原始任务payload。
变更通过新增迁移实现；初始001_schema.sql不可拿来覆盖现有.local/dev-db。旧音频验证后回填，无法验证的保留旧资源并标记待重新生成；本轮不执行迁移。

四、并发、重试与费用控制
数据库唯一键保证同参数只有一个缓存对象；事务内创建/查找并领取任务。合成和OSS网络调用在事务外进行。
Worker领取时生成递增fencing_token，租约初始180秒、每30秒续租；仅匹配当前租约代数的Worker可完成写回。对象路径包含缓存哈希及尝试代数，旧Worker不会覆盖新文件。
合成超时60秒，下载供应商结果30秒，OSS上传30秒；单文件不超过10MB，文本不超过1000字符。只接受已保存的词或句资源ID，API不接收任意朗读文本/外部音频URL。
默认每个音频最多3次合成尝试（包括首次）；仅网络抖动、限流、供应商5xx可退避重试，至少5秒/30秒并尊重Retry-After。无效音色、无权限、敏感输入不自动重试。
合成完成而OSS临时失败时，优先重试上传同一份已校验文件；服务端私有临时目录最长保留24小时。重启或文件丢失可能需要重新合成，不承诺外部费用严格exactly-once。
即使超时不知道供应商是否已计费，该尝试仍记额度。默认每孩子每日300次、每账号600次新合成尝试；并发初始2。缓存命中、排队等待与下载不计合成额度，但接口/下载仍有限流。
开发验收限额先收紧至每孩子20次、每账号40次，并发1；不要求一次性充值大量额度。账单告警不是硬性停费，程序额度与服务端熔断均要生效。
TTS不可用但已缓存文件可读时，已有音频继续播放；未配置TTS只阻止新合成，不应阻断缓存查询。

五、存储与下载
使用私有OSS标准存储，区域优先与后端ECS一致。文件路径类似 staging/audio/private/<opaque-child-id>/<hash>/<attempt>.mp3 或 staging/audio/public/<hash>/<attempt>.mp3，不使用姓名、单词原文作路径。
后端只接受配置的OSS桶和前缀，不让模型或客户端控制上传目标；供应商下载域名保持白名单、HTTPS、禁止重定向，不转发供应商API Key。
成功条件是：文件大小/MP3头校验通过，计算校验和，OSS写入成功后再把数据库状态置为succeeded。数据库落库失败留下的孤立文件由清理任务处理，不把失败记录当缓存命中。
下载接口每次验证当前会话、家庭成员、孩子、资源版本；只返回音频流与安全响应头，Cache-Control: private,no-store，不返回永久公共URL、OSS凭证或供应商临时URL。
前端通过downloadFile携带Authorization下载临时文件，再用InnerAudioContext播放本地路径；前端不请求OSS，开发阶段不需要OSS跨域配置或CDN。
客户端下载后再次播放仍经授权检查；切换账号/孩子清理私有临时缓存。已下载文件无法远程撤回，不声称授权撤销能抹除设备字节。
OSS返回404先标记资源缺失并进行受限修复；403、超时或网络故障不能当“缺失”反复触发TTS。修复仍受并发去重和每日额度约束。
音频引用仍有效则保留；过期版本/孤立文件经引用检查与30天宽限后清理。不得给整个音频前缀简单设置30天自动删除。删除孩子时立即撤销播放入口，按数据生命周期删除其私有对象；公共对象仅删除绑定，避免影响其他家庭。
API代理会消耗服务器带宽；先确保安全、可运行，后续以监控数据决定是否改为短时签名/CDN，不承诺“缓存后完全免费”。

六、接口约定（沿用0.1契约，业务实现待接入）
GET /voices：返回已配置且经实际账号验证的音色和口音，不能仅因为官方有目录就声称本账号可调用。
POST /audio：Idempotency-Key必填；提交word_id或sentence_id（二选一）、content_version、accent、voice_id、speech_rate。缓存命中200 Audio；未命中/生成中202 JobAccepted(job_id,status,poll_after_ms)。先验权限再返回幂等结果。
GET /jobs/:id：查询自己的家庭任务。audio任务成功仅返回本家庭audio_id，不透传全局cache key、OSS key或模型payload。
GET /audio/:id/content：鉴权下载。内容未准备好409，资源不再可访问404，版本已更新409/410。播放器不会把错误JSON当MP3播放。
POST /jobs/:id/retry：失败且可重试时复用任务/缓存对象；保留累计attempts，只重做未完成阶段，调用前重新检查额度和权限。
/dictionary/audio与其content接口仅在受信词典可用后启用，并保持查询限流；不允许使用任意candidate_id猜测公共资源。
生成失败提示“音频生成失败，点击重试”；播放网络失败只重试下载。生成与播放失败必须区分。

七、资源交接
A. 现在准备：阿里云百炼北京业务空间、CosyVoice模型调用权限和可用额度；Workspace ID；对应地域API Key（只写本机.env/服务端环境变量）。
沿用cosyvoice-v3-flash，不因目录出现新模型就自动升级。候选默认女声：英音loongemily_v3、美音loongabby_v3；要先在该账号分别试合成，试听确认后纳入白名单。
B. 现在准备：一个私有OSS测试桶（标准存储），提供Bucket名称、地域、Endpoint。先独立staging前缀，生产使用独立桶或严格独立凭证/前缀。
C. 现在准备：服务端OSS身份。ECS部署优先RAM角色/临时凭证；本机联调用专用RAM身份或STS凭证，限定测试桶staging/audio/*的GetObject/PutObject，不用主账号AccessKey。不需要上传真实密钥到聊天。
D. 告知现状：是否已有ECS、所在地域、部署方式，是否已有可用HTTPS API域名。没有也可先本机完成TTS+OSS联调，不为本次准备GPU、CDN或额外手机号登录服务。
E. 真机前：配置API HTTPS域名，在微信后台配置request及downloadFile合法域名；本方案前端仅访问API域名，不直接访问OSS。AppID已知无需重复提供；正式微信登录AppSecret仅服务端配置。
F. 可选偏好：男/女声、默认英音/美音。若不调整，保留孩子现有口音设置，使用上述两种女声、语速1.0。
可公开回传：Workspace ID、桶名、地域、Endpoint、ECS/域名是否就绪、已启用音色、配置项是否已填写。请勿回传API Key、AccessKey Secret、STS Token或AppSecret。

八、验收清单
同词同参数连续播放10次只合成1次；并发10个请求只产生一次活跃合成，等待方收到相同内容但只看自己的授权句柄。
英美音、不同音色/语速/词性发音、不同模型策略不串用；公共标准词跨家庭复用、私有句子不跨孩子复用。
角色被移除、内容改版、伪造资源ID无权下载；缓存命中也必须鉴权。
超时/限流/非法音色/坏文件/上传失败/OSS404与403分别有正确恢复，未配置TTS仍可读旧缓存。
Worker崩溃与租约过期后旧Worker不能覆盖新结果；累计调用额度不因重试重置；不可恢复错误不会自动扣费循环。
真实账号至少试听airport、luggage、delay、read/record等易混词及两条例句；同形异音不可靠时改用经过授权的词典发音或明确标记，不把TTS猜测当权威发音。
真机验证下载、切换停止、弱网重试、两位家长、失去权限后的播放；记录实际命中率、首播时延、TTS次数、存储与流量费用，不虚报实测数据。
