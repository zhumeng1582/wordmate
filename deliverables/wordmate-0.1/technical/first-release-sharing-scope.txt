单词共学 / Wordmate 首发共享范围
确定日期：2026-10-24
状态：前后端已按首发范围收口，通过本地服务端回归和小程序构建检查；尚待生产部署与真机验收。

首发定位
首发以家庭共学为核心：同一家庭获批家长共同管理孩子学习，用户可主动转发学习成果或导出词汇。
跨家庭公开词本发布、搜索、预览和加入不进入首发。后续补齐内容治理后再独立开放。
本决定依据当前实现和工程缺口，不代表微信审核或法律适用结论。

保留的能力与边界

1. 家庭内部共学
   有效家庭成员可按现有权限访问本家庭孩子的词本、学习和复习进度、日历、错题及月测。
   “家庭内共用”不需要打开词本公开开关；默认不向其他家庭开放数据。
   同家庭内不同孩子继续保留各自词本、卡片与学习记录，不因共享合并学习进度。

2. 邀请另一位家长
   保留管理员生成邀请口令/卡片 → 被邀请人登录并主动申请 → 管理员批准的流程。
   保持当前 24 小时有效、一次领取规则；链接落地页不展示孩子和家庭学习资料。
   拿到邀请链接、登录或提交申请均不直接获得家庭访问权限。
   普通小程序转发、好友邀请和 CSV 文件都不能替代家庭审批。
   所有发送由用户在微信中选择收件人；取消不记为分享成功。

3. 学习成果卡
   保留用户主动生成预览、分享给朋友和保存相册。
   内容仅含学习日期、学习词数、目标、是否打卡、连续打卡天数、鼓励语与背景。
   不加入孩子昵称、头像、年级、性别、家庭名称、具体错词、完整学习历史或测验成绩。
   分享卡片链接只落到小程序首页，不为收件人提供访问原孩子记录的能力。
   保留 AI 来源提示；具体生成内容标识与微信后台要求仍属于独立上线验收项。

4. CSV 导出及主动转发
   保留家长选择本孩子词条/整个词本，再通过微信原生界面主动发送文件。
   字段限定为：单词、词性、中文释义、英式音标、美式音标、英文例句、例句翻译、内容来源。
   不新增孩子档案、用户/家庭/孩子标识、访问令牌、复习历史、错题统计或月测成绩。
   文件是学习材料副本，不建立在线订阅、跨家庭访问授权或学习进度同步关系。
   文件和图片被用户转发后无法由本服务远程撤回；源词本权限变化只控制本服务内的数据访问。

5. 普通小程序及好友邀请
   保留普通小程序卡片转发和现有新用户首次邀请归因。
   转发不包含孩子学习数据，也不自动申请或加入家庭。
   邀请归因关系不向其他用户公开，不在首发新增奖励、排行榜或邀请任务。
   隐私文本需明确邀请归因所处理的账号关系；邀请人身份不能作为家庭授权依据。

暂缓的能力

- 用户把词本公开给所有账号搜索、查看或加入。
- “发现共享词本”、公共词本详情和跨家庭只读订阅。
- 使用私密链接、口令或二维码跨家庭分发在线词本；首发不新增这类替代通道。
- 公共评论、用户主页、关注、点赞、排行榜和邀请奖励。

代码收口（已实施）

1. 普通词本移除“共享设置”“发现词本”“发现共享词本”等公开入口；历史已发布词本只提供停止共享，历史已加入词本保留离开入口。家庭邀请、成果卡、导出、普通好友邀请保留。
2. 公开发现/详情页面不进入正式页面注册；历史路径不能绕过服务端限制。
3. 服务端拒绝公开词本搜索、预览、新加入和发布/重新发布。必须在服务端校验，不能只隐藏按钮或信任客户端参数。
4. 允许合法发布者停止既有共享；允许已有订阅者离开词本。停止共享和离开不受“禁止新公开”的限制。
5. 已加入用户的本地词汇快照和学习进度保留，继续按本家庭权限学习、复习及导出；不自动删除或迁移真实学习数据。
6. 正式发布检查应验证公开能力关闭，构建参数或深链不能开启服务端禁止的功能。
7. 页面文案、隐私说明和提审材料统一使用本范围；“自己的词本”应说明家庭获批成员也可共同访问，避免误解为仅创建者可见。

首发验收

- A 家庭成员可正常共学；未获批账号、B 家庭及未登录账号不能访问 A 家庭资料。
- 邀请申请前和管理员批准前不可查看家庭资料；过期邀请不可领取。
- 成果卡预览及导出字段符合上述边界；微信取消发送不显示“已发送”。
- 直接调用旧公开搜索、详情、加入及发布 API 仍被拒绝；不能通过旧页面或深链恢复公开访问。
- 已有快照的学习进度保留；停止共享、离开词本及正常词本删除行为可用。
- 普通好友邀请只打开小程序；邀请归因不会赋予家庭访问权限。

后续开放公开词本的条件

具备发布审核、举报、运营下架及申诉/处置流程；核对用户导入材料和共享内容的使用授权；完善公开副本、停止共享及删除规则；同步隐私文本，并完成对应平台要求与真机验收。
公开共享作为单独能力重新验收，不随首次上线默认开放。

工程验证入口

corepack pnpm test:release-scope：直接服务调用、旧成功幂等请求拒绝、历史副本进度、发布者权限、停止/退出与归档回归。
corepack pnpm build:api && corepack pnpm test:routes：真实 Nest/Express 管线验证旧公开 API 返回 403 PUBLIC_SHARING_DISABLED。
corepack pnpm build:miniapp && node scripts/check-miniapp.cjs：16 个注册页面，发现页面未注册且不进入产物，无公开发布入口，保留历史管理入口。
corepack pnpm build:release：要求正式 HTTPS API 地址，构建后自动运行上述产物检查；不表示后端已部署或微信审核通过。
关闭能力写入服务代码，没有可通过环境变量、请求参数或客户端构建参数开启的开关。后续开放须另行改代码和验收。
