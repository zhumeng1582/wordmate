已确定的实现方案

前端：Taro + React + TypeScript + SCSS。后端：NestJS + TypeORM + PostgreSQL。任务：Redis + BullMQ，PostgreSQL持久任务表保证可恢复。记忆调度：ts-fsrs。文本生成：默认DeepSeek，可配置切换OpenAI或千问；英美语音：阿里云CosyVoice适配器；私有文件：阿里云OSS。

默认月测范围为所选月学过的义项，抽样10/20/30/50或全量；优秀≥90、良好≥80、合格≥60、待加强<60。孩子的每月试卷和每次错误都保留独立事实。
